BACKGROUND MUSIC
Put royalty-free tracks (.mp3 / .wav / .m4a) in these folders. A Script Pack says which mood it wants ("music": "epic").
  assets/music/epic/        big, powerful (fights, gods appearing)
  assets/music/devotional/  calm bhajan-like, flute, tanpura
  assets/music/suspense/    slow, tense, mysterious
  assets/music/sad/         emotional
  assets/music/calm/        soft ambience
If the mood folder is empty, any file directly in assets/music/ is used, and if there is none, the software makes a simple synthetic ambience (this is the weak one, add real tracks).
Use only music you may use commercially (YouTube Audio Library, Pixabay Music, or tracks you bought). Keep 3-5 tracks per mood, 60 seconds or longer, no vocals.
